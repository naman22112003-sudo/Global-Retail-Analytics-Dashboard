# Global-Retail-Analytics-Dashboard
🚀 Just built a full-scale Sales & Revenue Intelligence Dashboard in Power BI — and I'm genuinely proud of this one.

3 reports. Dozens of visuals. And a workflow that finally feels like the future of analytics.

Here's what went into it 👇

📊 What I built:
→ 3 interconnected reports covering Sales Performance, Revenue Trends & KPI Tracking
→ Advanced DAX measures & calculated columns for dynamic insights
→ Power Query / M language for clean, scalable data transformation
→ Bookmarks & Drillthrough for seamless storytelling across reports
→ Custom visuals to go beyond the default Power BI library
→ Personalized view for each user role
→ Search-enabled slicers for instant data navigation
→ MCP Server integration — bringing AI-assisted development directly into my Power BI workflow
→ Deployed on Microsoft Fabric for enterprise-grade scalability

- Integrated Model Context Protocol (MCP) server with the local model, accelerating DAX development, Relationship Management
speed.
- Designed a seamless, 4-tab interactive navigation flow (Sales, Profit, Return, Customers) using advanced Bookmarks to speed up
executive review.
- Authored 12+ dynamic DAX metrics to identify why specific high-volume items fell into the "Bottom 5" for net profit despite $12.64M in
total sales.
- Visualized global retail data across 165 countries and 1102 states to isolate the United States and Texas as the primary regional
revenue drivers.
- Developed a specialized tracking system for 2,220 product returns to pinpoint high-defect lines and minimize profit leakage.
- - Published the ecosystem onto Microsoft Fabric to automate scheduled refreshes and eliminate hours of manual weekly reporting

🤖 The MCP Server integration was a game-changer. Being able to work with an AI assistant inside my development environment cut hours off my build time and helped me write cleaner DAX faster than ever before.

💡 My biggest takeaway: Power BI is no longer just a reporting tool — it's a full analytics platform when you combine Fabric, MCP, and advanced data modeling together.
